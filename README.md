# Magical Glitter Sand Slate (Wooden Stick Edition)

This is a complete Jetpack Compose Android app simulating a physical glitter sand slate.

## Build Instructions

### Option 1: Automatic Cloud Build (GitHub Actions)
1. Push this repository to GitHub.
2. Go to the **Actions** tab in GitHub.
3. Once the **Build Debug APK** workflow finishes, download the APK from **Artifacts**.
